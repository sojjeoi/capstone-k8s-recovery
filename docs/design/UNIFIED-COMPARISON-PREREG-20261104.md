# 통일 비교 사전 등록 (2026-11-04)

> 실행 전 고정 문서. 결과를 보고 군·횟수·지표·순서·중단 기준을 바꾸지 않는다. 바꿔야 하면 새 판(rev)으로 남기고 이유를 적는다.

## 0. 근거
- 지도교수 피드백(경진대회 후): ① CPU 압박과 네트워크 지연의 비교군이 서로 다르다 → 통일 ② 전체적으로 반복 횟수가 적다.
- 사용자 승인(채팅 2026-11-04): "준비 + 필수 단계까지 오늘 진행", "충분히 확보되는 만큼 최대한 진행, 논문에서 신뢰할 수 있을 만큼의 반복 횟수로", "새벽부터 다음날까지 그리고 계속 작업 진행 가능".

## 1. 비교 군 (모든 장애에 같은 4군)
| 군 | 구성 | 조치 |
|---|---|---|
| C 무전환 | 서비스 Pod 1개, HPA 없음 | 없음 |
| H 오토스케일링 | 서비스 Pod 1개 + CPU HPA(목표 request 대비 100%, 최대 2) | 확장만 |
| W 계속 분산 | Ready Pod 2개가 같은 Service | 없음 |
| G 우리 시스템 | 서비스 Pod 1개 + Ready 예비 Pod 1개, guarded 정책 act | 선택된 감지기 신호 → 예비 Pod 전환 |

G 감지기(Phase 2 선택 결과): F1 CPU 압박 = cpu-threshold-c, F2 네트워크 지연 = net-probe-readiness, F3 요청 폭주 = cpu-threshold-c(기존 비교와 같음).

## 2. 장애 (기존 동결 정의 그대로)
- F1 CPU 압박: StressChaos cpu workers 1·2·3·4(load 100) × 90 s, 시작 시점 서비스 Pod 1개에 고정(run_cpu_demo_trial.DEMO_STAGES). G는 전환 뒤에도 원래 Pod에 남은 단계를 계속 건다(Phase 2 Stage 2 act와 같음, continue_after_target_replacement=True).
- F2 네트워크 지연: NetworkChaos 500/1000/2000/4000 ms(지터 10%) × 90 s, 시작 시점 서비스 Pod 1개에 고정.
- F3 요청 폭주: chaos/scenario-load-ramp.yaml(기존 비교와 같음).

## 3. 공통 조건
- probe 프로필 11초(network_tolerant) 공통, 관찰 = 주입 후 600 s, probe 1 RPS·max_tokens=1, 서비스 Pod 시작 노드 sj-worker 고정.
- 지표: SLO 위반 누적(초) = slo_episodes.violation_episodes r2 cumulative_sec(SLO v3: 60 s 창 P95 > 0.648 s가 30 s 지속 또는 성공률 < 99%, 회복 = 30 s 정상 지속). 보조: Pod 유지량(Pod·초), G의 요청 이동 판정(새 Pod ≥ 30, 기존 ≤ 2).

## 4. 횟수와 순서
- 목표: 모든 (장애 × 군) 칸 **유효 5회**(발표 전 목표), 이후 시간이 되면 **유효 10회**까지 같은 규칙으로 확장.
- 기존 유효 세션(HPA 비교 F2 H·W 3회, G 4회, F3 H·G 2회)은 그대로 칸에 포함한다(같은 하네스·같은 조건). 새 세션은 다른 날짜임을 기록한다.
- 블록 = 한 장애에서 4군 각 1회. 블록마다 군 순서를 한 칸씩 돌린다(k번째 블록: [C, H, W, G]를 k-1칸 회전).
- 우선순위: F1(빈칸) → F2 → F3.
- 기존 CPU A/B 8쌍(c1 IF 감지기, Phase 1)은 이 표에 합치지 않고 별도 근거로 보존한다.

## 5. 무효·중단 규칙
- 하네스 오류(classification == harness_error, 예: 사전 안전검사 중단·측정 시계 불일치)만 무효, 같은 칸 1회 재시도. 복구 실패·미회복·나쁜 결과는 유효한 결과다.
- 다른 작업과 충돌(blocked_by_other_work)이나 복원 실패가 나면 순서를 멈추고 보고한다. 안전검사 기준을 낮추지 않는다.
- 결과를 보고 장애 세기·관찰 시간·기준값을 바꾸지 않는다.

## 6. 분석
- 칸별 중앙값·범위·전체 값 표. 군 간 비교는 칸별 원값과 Mann-Whitney U(양측) 참고값을 함께 보고, 통계적 결론은 표본 수 한계와 함께 적는다.
- F1에서 H가 G보다 좋게 나와도 그대로 보고한다.
